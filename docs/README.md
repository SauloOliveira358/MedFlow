As experiências são: paciente (agendar a própria consulta), especialista (agenda, pacientes e prontuários) e clínica (operação completa). O PDF original continua sendo referência acadêmica; esta entrega segue a solicitação posterior e não representa o MVP integrado exigido pelo documento.

Todas as pessoas, avaliações, documentos e observações são fictícios. O protótipo funciona no navegador e mantém alterações locais para demonstração.
